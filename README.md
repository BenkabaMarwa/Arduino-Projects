# 🤖 Arduino Projects

A collection of practical Arduino projects created for learning electronics,
programming, sensors, and automation through hands-on experimentation.

The projects are organized progressively, starting from basic LED control
and moving toward sensor-based projects and Arduino + Python interactions.

---

## 📚 Projects

### 💡 Basics

| # | Project | Description |
|---|---|---|
| 01 | LED Basics | Control a basic LED |
| 02 | Push Button LED | Control an LED using a push button |
| 03 | Potentiometer | Read analog values from a potentiometer |
| 04 | Potentiometer LED Delay | Control LED timing using a potentiometer |

### 🔊 Potentiometer Projects
